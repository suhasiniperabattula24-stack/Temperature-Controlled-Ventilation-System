# 🌡️ Temperature Controlled Ventilation System

An Arduino UNO-based embedded system that monitors ambient temperature using a DHT11 sensor, displays readings on a 16×2 LCD, and indicates temperature levels using LEDs.

## 🎯 Objective

To develop a temperature monitoring system that measures ambient temperature, displays readings on an LCD, and provides visual alerts through LEDs based on predefined temperature thresholds.

## ✨ Features

- Real-time temperature monitoring
- LCD-based temperature display
- Three-level temperature indication
- LED-based visual alerts
- Simple and cost-effective design

## 🛠️ Components Used

- Arduino UNO
- DHT11 Temperature Sensor
- 16×2 LCD Display
- Green LED
- Yellow LED
- Red LED
- Resistors
- Breadboard and jumper wires

## ⚙️ Working Principle

The DHT11 sensor measures the surrounding temperature and sends the readings to the Arduino UNO. The Arduino processes the data, displays the temperature and status on the LCD, and activates the corresponding LED.

- 🟢 **Green LED:** Normal temperature
- 🟡 **Yellow LED:** Moderate temperature
- 🔴 **Red LED:** High temperature
